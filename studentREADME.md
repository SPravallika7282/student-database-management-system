# Student Database Management System
## About
A web-based Student Database Management System built using Python, Django, JavaScript, HTML and CSS.

## Features
- Add Student details
- View all student records
- Update student information
- Delete student records
- Search student details

## technologies used
- Python
- Django
- JavaScript
- HTML
- CSS
- SQLite

## Database
SQLite

## project Objective 
To manage student information efficiently through a simple web application.
